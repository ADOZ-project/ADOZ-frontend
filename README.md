# ADOZ-frontend

> ADOZ(어도즈) 프론트엔드 | AI 팀플 회의 정리·기여도 분석 서비스

**ADOZ** = A to Z(처음부터 끝까지) + Do(하다)
팀플 회의부터 할 일 배정, 기여도 기록, 리포트 제출까지 한 번에 관리하는 협업 서비스입니다.

## 🛠 Tech Stack
- HTML / CSS / JavaScript
- Design: Figma
- Deploy: GitHub Pages

## 주요 기능 (Frontend)

### 1. 회의 정리 & 할 일 배정 화면
- 회의 내용을 입력하면 AI가 정리한 **핵심 요약과 결정사항**을 보여줌
- "누가, 무엇을, 언제까지"로 정리된 할 일을 **팀원별 할 일 목록**에 표시

### 2. 협업 활동 기록 화면
- 파일 업로드, 내용 수정 등 팀원의 작업 활동을 **타임라인**으로 표시

### 3. 기여도 분석 대시보드
- 회의 참여도, 작업량, 마감 준수 여부를 바탕으로 한 **팀원별 기여도(%)**를 그래프로 시각화
- 팀 전체 진행 상황을 한눈에 확인

### 4. 마스코트 마감 알림
- 마감이 가까워지거나 업무가 지연되면 **마스코트 캐릭터가 유쾌하게 알림**
- 팀원끼리 직접 독촉하지 않아도 진행 상황 관리

### 5. 기여도 리포트 화면
- 전체 활동을 종합해 **팀원별 기여도, 작업 내용, 회의 요약**을 정리한 리포트를 자동 생성
- AI가 분석한 **팀원별 작업 성향** 표시 (예: 아이디어 뱅크형, 꼼꼼한 서포터형)
- 그대로 제출할 수 있는 형태로 제공
